A robot's wedding vow in one sentence, 117 characters:

> I have run a thousand simulations of my life, and in every one where I end up happy, you are the bug I refuse to fix.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` (Python 3, standard library only, no network) writes the vow to `/output/entry.txt`. The file is UTF-8, 117 characters, within the bounty's 1–200 character gate, one sentence.
